## Local preview

`python3 -m http.server 8000`, then open <http://localhost:8000>.

## Updating images

Images come from the Clipdori repo: `marketing/branding/icon-master-1024.png` resized with `sips --resampleWidth 256` (`assets/icon.png`), and `marketing/app-store/exports/<lang>/iphone/*.png` resized with `sips --resampleWidth 480` (`assets/<lang>/`).
